# Airport Management System ✈️

A console-based Airport Management System built in **Python** using 
Object-Oriented Programming (OOP) concepts.

## Features
- Add new flights with flight number and destination
- View all available flights
- Book tickets for passengers
- View all booked passengers

## Technologies Used
- Language: Python
- Concepts: OOP (Classes & Objects)
